# Doka Software Homebrew Tap

```bash
brew install doka-software/tap/translatus
```

| Formula | What it is |
|---|---|
| `translatus` | Translate and annotate whole books with your own LLM, locally — [doka-software/translatus](https://github.com/doka-software/translatus) |

Formulae build from source (Rust toolchain supplied by Homebrew).
